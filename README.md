# Student_Attendance_Analytics

## 📌 About the Project

This repository demonstrates various data manipulation, cleaning, and analysis operations that can be performed on an Excel file using **Python Pandas**.

The project uses the `CSEB_Attendance.xlsx` dataset to analyze student attendance, identify students at risk due to low attendance or consecutive absences, and generate useful summaries for attendance monitoring.

## 📂 Project Files

- `CSEB_Attendance.xlsx` – The dataset used for the analysis.
- `Project_Student Attendance Analytics with Pandas.ipynb` – The Jupyter Notebook containing the code and analysis.
